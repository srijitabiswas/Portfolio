# 🌐 Srijita Biswas – Portfolio Website

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/srijitabiswas/Srijita_Portfolio.git
```

Navigate into the project:

```bash
cd Srijita_Portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
